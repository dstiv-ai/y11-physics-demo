# Year 11 Physics · Next step

[Open the public demo](https://dstiv-ai.github.io/y11-physics-demo/)

A short Physics gap check, written-practice feedback demonstration, and fictional teaching snapshot. No sign-in. All examples and class data are made up. Written feedback is pre-authored and simulated; custom responses are not AI-marked.

Only built static files are kept here. No application source project, backend, keys, external AI calls, analytics or response storage. Selected outcomes from the NSW Physics Stage 6 Syllabus (2017); not a full exam or syllabus assessment.
